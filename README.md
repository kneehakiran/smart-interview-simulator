# 🎤 Smart Interview Simulator

A Python-based interactive interview simulation project designed to help users practice HR and technical interview rounds while receiving dynamic feedback and performance evaluation.

## 🚀 Features

* HR & Technical Interview Rounds
* Dynamic Question Flow
* Performance Scoring System
* Randomized Feedback Responses
* Final Interview Evaluation
* Automatic Report Generation
* File Handling using Python

## 🛠️ Technologies Used

* Python
* Random Module
* File Handling
* Dictionaries
* Nested Loops
* Conditional Logic

## 📌 Project Workflow

1. User enters their name
2. Interview rounds begin
3. Questions are displayed category-wise
4. User responses are evaluated dynamically
5. Performance score is calculated
6. Final feedback is displayed
7. Interview report is saved automatically
